# Finalyze   
Live Demo:https://finalyze-1.onrender.com/
### Smart Expense Tracking Web Application

Finalyze is a lightweight and user-friendly expense tracking web application built using Flask.  
It helps users record, manage, and monitor daily expenses efficiently.

---

##  Project Overview

Managing expenses is essential for financial awareness and planning.  
Finalyze provides a simple interface to track spending habits and maintain better financial control.

This project was developed as part of practical learning in Python web development using the Flask framework.

---

## Features

- Add daily expenses
- View recorded expenses
- Organized and clean user interface
- Lightweight and easy to run
- Structured project architecture
- Beginner-friendly implementation

## ▶ How to Run the Project

1. Clone the repository:
   ```
   git clone <your-repository-link>
   ```

2. Navigate to the project folder:
   ```
   cd Finalyze
   ```

3. Install dependencies:
   ```
   pip install flask
   ```

4. Run the application:
   ```
   python app.py
   ```

5. Open your browser and visit:
   ```
   http://127.0.0.1:5000/
   ```
