A simple project to track daily expenses.

## Features
- Add new expenses
- View expense history
- Categorize expenses (Food, Travel, Bills, etc.)
- Calculate total expenses

## How to Run
1. Open `index.html` in your web browser.
2. Add your expense details and see the tracker in action.
